# fetch-script

### Как проверить: 
1) Клонируйте репозиторий: `git clone https://github.com/rennaiis/fetch-script`
2) Убедитесь, что на компьютере установлен node.js
3) Откройте папку с проектом в терминале
4) Установите зависимости: `npm install`
5) Запустите программу: `node script.ts "[любой URL]" `
* Скорость измеряется в килобайтах в секунду, время в секундах, объем в байтах
